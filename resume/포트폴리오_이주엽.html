01. AI 에이전트를 활용한 퍼블리싱 자동화 시스템 설계

2024.01 - 2024.05 | 기여도 100% | 주식회사 이트라이브 (개인 가이드라인 구축)
Claude/Anti-gravity Custom Rules(SKILL.md) Agile Workflow
[ AI 에이전트 커스텀 룰 설계 및 마크업 자동 변환 파이프라인 화면 ]
  • 배경: 수백 개의 레거시 페이지를 단기 기한 내에 신규 표준 가이드로 전환해야 하는 대규모 고도화 프로젝트 직면.
  • 핵심 성과: AI 에이전트 전용 **퍼블리싱 프롬프트 및 규칙 시스템(Custom Rule)**을 독자 설계하여, 단순 활용을 넘어 **반복 공수의 80% 이상을 자동화**하는 파이프라인 구축.
⚠️ Troubleshooting: AI 결과물의 코드 일관성 및 휴먼 에러 제어
[문제] 일반적인 AI 코드 생성은 프로젝트 고유의 BEM 네이밍이나 공통 모듈 구조를 무시하여 사후 수정 비용이 발생하는 문제 발생.
[해결] 프로젝트별 CSS 가이드라인과 컴포넌트 사용 원칙을 명문화한 **Rule 파일(SKILL.md)**을 작성하여 에이전트에 사전 주입함으로써, 코드 일관성을 95% 이상 확보함. 이는 단순 속도를 넘어 팀 전체의 유지보수 품질을 상향 평준화하는 결과를 가져옴.

02. 마케팅 성과 극대화를 위한 성능 최적화

2023.06 - 2023.12 | 기여도 100% | 삼성자산운용 외 마케팅 프로젝트
Next.js Core Web Vitals GA4/GTM SEO
웹 포트폴리오(Interaction 확인)
  • 배경: 광고 유입 대비 높은 초기 이탈률 개선 및 정교한 사용자 데이터 추적 세팅 필요.
  • 핵심 성과: **LCP(초기 로딩 속도) 개편 전 5.2s → 개편 후 1.8s**로 단축. 이탈률 약 30% 방어.
⚠️ Troubleshooting: 높은 페이지 이탈률과 로딩 지연 해결
[문제] 고화질 이미지와 복잡한 인터랙션으로 인해 모바일 환경에서의 초기 로딩 지연이 심각했고, 이는 GA 데이터상 높은 이탈률(Bounce Rate)로 이어짐.
[해결] Next.js의 Image Optimization을 적용하고, 폰트 서브셋 구성 및 불필요한 JS 라이브러리 제거를 수행함. 또한 GTM을 통해 이탈 지점을 추적하여 UI 배치를 수정한 결과, 사용자 체류 시간이 기존 대비 45% 증가하는 비즈니스 임팩트를 창출함.

02. 브랜드 가치를 높이는 고성능 인터랙션 UI

2023.01 - 2023.07 | 기여도 100% | LG화학 채용 사이트 메인 리뉴얼
GSAP SVG Animation SCSS Vanilla JS
사이트 방문하기
  • 배경: 커리어 5~6개월 차에 삼성자산운용 운영과 병행하며, 단 일주일 내에 메인 페이지 고난도 인터랙션 완수 요구됨 (단독 처리).
  • 핵심 성과: **GSAP 및 SVG Path 애니메이션** 최초 도입. 촉박한 일정 속에서도 리서치와 구현을 병행하며 픽셀 단위의 모션을 완벽 구현.
⚠️ Troubleshooting: 생소한 기술 도전과 극한의 일정 관리
[문제] 기업 아이덴티티를 담은 정교한 인터랙션이 필수적이었으나, 생소했던 기술적 한계와 타 프로젝트 운영 병행이라는 리소스 압박이 있었음.
[해결] 공식 문서를 통한 **GSAP** 조기 독학 및 SVG Path 드로잉 기법을 직접 제안/구현함. 멀티태스킹 능력을 발휘해 기한 내 성공적으로 마감하며, 신입 이상의 돌파력과 결과물 품질을 인정받음.

03. 대규모 플랫폼 아키텍처 및 공통 컴포넌트 설계

2023.01 - 2023.12 | 삼성자산운용 펀드솔루션 및 롯데 VL 시니어 레지던스
CSS Grid/Flexbox WCAG 2.1 Component Design
  • 배경: 방대한 금융 데이터의 가독성 확보(삼성) 및 시니어 타겟의 웹 접근성 극대화(롯데 VL)가 핵심 과제.
  • 핵심 성과: 전사 공통 컴포넌트 라이브러리 및 반응형 가이드라인을 수립하여 작업자 간 품질 파편화를 방지하고 유지보수 효율 증대.
⚠️ Troubleshooting: 다인 협업 환경에서의 코드 일관성 확보
[문제] 다수의 작업자가 투입된 환경에서 스타일 충돌과 불필요한 중복 코드가 프로젝트 안정성을 해치는 리스크 직면.
[해결] **SCSS 변수 및 믹스인 체계**를 직접 설계하여 가독성 높은 공통 가이드를 배포함. 삼성 프로젝트에서는 결함 제로(Zero)를, 롯데 VL에서는 **웹 접근성 우수 마크 획득**에 기여하며 전문성을 입증함.

04. 현대적 프론트엔드 생태계로의 전환 및 최적화

2022.06 - 2022.12 | 큐브 리펀드 리뉴얼 구축
React TypeScript SCSS Module
  • 배경: 레거시(jQuery) 환경에서 React/TypeScript 기반의 SPA 아키텍처로 전환하며 퍼블리싱 플로우 고도화 필요.
  • 핵심 성과: 컴포넌트 기반 UI 설계와 스타일 캡슐화(SCSS Module)를 통해 협업 프로세스 혁신 및 사후 관리 효율 40% 이상 향상.
⚠️ Troubleshooting: 컴포넌트 기반 아키텍처의 스타일 격리
[문제] SPA 환경에서 전역 스타일 오염 문제와 상태(State)에 따른 UI 전환 처리가 기존 방식으로는 한계에 부딪힘.
[해결] SCSS Module을 적극 활용해 스타일 간섭을 원천 차단하고, 아토믹 디자인 패턴을 적용해 재사용 가능한 디자인 시스템의 기반을 마련함. 프론트엔드 개발자와의 긴밀한 싱크를 통해 효율적인 개발 환경을 구축함.
