01. AI 기반 고속 퍼블리싱 자동화 파이프라인 (Efficiency Innovation)

2024.01 - 2024.05 | 기여도 100% | 주식회사 이트라이브 (LOTTE EATZ 외)
Claude/Anti-gravity Custom Rules(SKILL.md) JavaScript
[ AI 프롬프트 설계 및 마크업 자동화 실행 화면 스크린샷 ]
  • 배경: 대규모 플랫폼 고도화 시, 수백 개의 페이지를 짧은 기한 내에 새로운 코딩 가이드로 전환해야 하는 상황.
  • 핵심 성과: AI Agent를 위한 퍼블리싱 규칙 시스템(Rules)을 독자 설계하여 **수작업 대비 개발 공수 80% 단축** 달성.
⚠️ Troubleshooting: AI의 마크업 일관성 및 에러 제어
[문제] 초기 AI 활용 시, 결과물이 프로젝트 고유의 스타일 가이드를 따르지 않거나 복잡한 테이블 구조에서 문법 에러가 발생하는 문제 발생.
[해결] 단순히 코드 생성을 요청하는 대신, 프로젝트 전용 가이드라인(Rule) 파일을 작성하여 AI 에이전트에 사전 학습시킴. 구체적인 CSS 네이밍 룰(BEM), 공통 컴포넌트 사용 원칙 등을 정의하자 정답률이 95% 이상으로 상승했으며, 이를 통해 팀 전체의 유지보수 일관성을 확보함.

02. 마케팅 성과 극대화를 위한 성능 최적화 (Customer Centric)

2023.06 - 2023.12 | 기여도 100% | 삼성자산운용 외 마케팅 프로젝트
Next.js Core Web Vitals GA4/GTM SEO
웹 포트폴리오(Interaction 확인)
  • 배경: 광고 유입 대비 높은 초기 이탈률 개선 및 정교한 사용자 데이터 추적 세팅 필요.
  • 핵심 성과: **LCP(초기 로딩 속도) 개편 전 5.2s → 개편 후 1.8s**로 단축. 이탈률 약 30% 방어.
⚠️ Troubleshooting: 높은 페이지 이탈률과 로딩 지연 해결
[문제] 고화질 이미지와 복잡한 인터랙션으로 인해 모바일 환경에서의 초기 로딩 지연이 심각했고, 이는 GA 데이터상 높은 이탈률(Bounce Rate)로 이어짐.
[해결] Next.js의 Image Optimization을 적용하고, 폰트 서브셋 구성 및 불필요한 JS 라이브러리 제거를 수행함. 또한 GTM을 통해 이탈 지점을 추적하여 UI 배치를 수정한 결과, 사용자 체류 시간이 기존 대비 45% 증가하는 비즈니스 임팩트를 창출함.

03. 브랜드 가치를 높이는 고성능 인터랙션 구축 (Major Brand & Agility)

2023.01 - 2023.07 | 기여도 100% | LG화학 채용 사이트 메인 리뉴얼
GSAP (ScrollTrigger) SVG Animation SCSS JavaScript
사이트 방문하기
  • 배경: 커리어 5~6개월 차에 삼성자산운용 운영과 병행하며, 단 일주일 내에 메인 페이지 고난도 인터랙션 완수 요구됨.
  • 핵심 성과: **GSAP 및 SVG Path 애니메이션** 도입. 복잡한 모션 시퀀스를 픽셀 단위로 구현하며 기한 내 성공적 마감.
⚠️ Troubleshooting: 생소한 기술 도전과 극한의 일정 관리
[문제] 스크롤에 반응하는 정교한 시각 효과가 필수적이었으나, 당시 생소했던 GSAP 라이브러리와 SVG 애니메이션을 단기간에 마스터해야 하는 기술적 장벽이 있었음.
[해결] 공식 문서와 국내외 커뮤니티를 통해 **GSAP ScrollTrigger**를 독학하여 즉시 실무에 적용함. 특히 LG화학의 '연결' 가치를 시각화하기 위해 **SVG Path 드로잉** 기법을 제안 및 구현하였으며, 운영 업무와 병행하는 멀티태스킹 능력을 발휘해 마감 기한 내에 성공적으로 결과물을 창출함.

상기 프로젝트 외 실무 코드 및 상세 GitHub 리포지토리는 웹 포트폴리오를 통해 확인 가능합니다.
